# Rota & Café

Um guia simples para descobrir cafeterias de bairros diferentes. O projeto foi
criado com Flask, Jinja2 e Bootstrap como exercício de site multipágina.

## Como executar

1. Instale as dependências: `pip install -r requirements.txt`
2. Inicie a aplicação: `python app.py`
3. Acesse `http://127.0.0.1:5000`

## Páginas

- Início
- Cafeterias
- Agenda
- Sobre
